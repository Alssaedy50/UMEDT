# UMED-2 Medical Data Center & AI Assistant User Guide

## 1. Getting Started with the Medical Data Center
Navigate to the **مركز البيانات** (Medical Data Center) tab from the bottom navigation on mobile or the top header on desktop.

The center contains 8 specialized tabs:
1. **استيراد الملفات (Import Files)**: Drag & drop or browse for PDF, Word, Excel, CSV, Text, Markdown, JSON, ZIP, or image files.
2. **مساعد الذكاء الاصطناعي (AI Data Assistant)**: Configure your personal Google Gemini API key and extract terms, MCQs, or clinical cases from uploaded documents.
3. **مدير الحزم (.umedpack Manager)**: Install `.umedpack` packages or export custom packs for specific medical specialties.
4. **مكتبة المحتوى (Medical Data Library)**: Search and explore terms, MCQs, and clinical cases stored on your device.
5. **سجل العمليات (Import History)**: View all past imports with 1-click Rollback capability.
6. **النسخ والاستعادة (Backup & Restore)**: Export complete database backups as `.zip` or create local snapshots.
7. **سلامة البيانات (Data Validation)**: Inspect schema version compatibility and integrity checks.
8. **المصادر والشفافية (Data Sources)**: Review provenance policies and confirm the 100% offline and cloud-only AI architecture.

## 2. Using the Cloud AI Assistant
1. Go to the **مساعد الذكاء الاصطناعي** tab.
2. Enter your Gemini API Key and click **حفظ** then **اختبار الاتصال**.
3. Select an uploaded file or paste medical notes.
4. Choose the task (e.g. "أسئلة الاختيار من متعدد MCQ").
5. Click **بدء الاستخراج والتحليل**.
6. Review the extracted records in the **Review & Staging** box, accept/reject items, and click **اعتماد وحفظ السجلات في قاعدة البيانات**.
